# Registro de decisiones

Aquí se anotan decisiones que afectan a todo el equipo. Así nadie tiene que adivinar por qué se eligió algo.

## D001 Un solo repositorio

- Estado: aceptada.
- Decisión: guardar frontend, backend, base de datos y documentación juntos.
- Motivo: el proyecto es de tamaño académico y un único repositorio simplifica la instalación, las revisiones y la coordinación de seis personas.

## D002 Tecnologías obligatorias

- Estado: aceptada.
- Frontend: Angular.
- Backend: Node con Express.
- Base de datos: MySQL.
- Motivo: son requisitos del enunciado.

## Plantilla para una decisión nueva

```text
## D000 Título corto

- Estado: propuesta, aceptada o descartada.
- Decisión: qué se ha decidido.
- Motivo: por qué se ha decidido.
```
