# Comercio online UNIR

Repositorio compartido para el proyecto final de una plataforma de compraventa de segunda mano.

## Estado actual

El repositorio contiene la estructura inicial y la documentación de organización. Todavía no se ha integrado el código funcional de Angular, Node/Express ni MySQL.

En Teams existen un prototipo visual y archivos de diseño de la base de datos. El equipo debe acordar cuáles son las versiones oficiales antes de incorporarlos al repositorio, manteniendo clara la autoría de cada archivo.

```text
frontend/   Aplicación Angular
backend/    Aplicación Node y Express
database/   Base de datos MySQL
docs/       Notas y acuerdos del equipo
```

El prototipo visual sirve para acordar las pantallas, pero no sustituye a la aplicación real: sus datos y acciones son simulados.

## Forma de trabajar

1. Elegir una tarea.
2. Crear una rama nueva desde `develop`.
3. Trabajar únicamente en esa rama.
4. Subir los cambios.
5. Abrir una pull request para que otra persona los revise.
